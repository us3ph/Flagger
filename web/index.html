About the model & evaluation +

A small, supervised classifier

TF-IDF features with a local scikit-learn classifier. No large language model or remote inference.

EverGreenQA provides auxiliary question labels. Project-authored statements bridge the gap to AI answers. The statement set needs independent human review before making research claims about general performance.
